## ✨ Features

### 👻 Ghost Mode
- Hide "seen" read receipts
- Hide typing indicator
- Hide online/offline status
- Hide story view status

### 🔒 Privacy
- Hide phone number
- Hide proxy sponsor

### 📥 Media
- Save secret media (disappearing photos/videos)
- Save stories
- Disable story deletion restrictions
- Remove content-saving restrictions

### 💬 Messages
- Show deleted messages
- Save message edit history
- Show message ID

### ⚡ Other
- Ultra-fast downloads
- Unlock Telegram Premium locally
- Disable number rounding (5.3K → 5300)
- Hide app update prompts
- Fix TL errors
- Custom calendar (Hijri / Persian / Gregorian)

## 📦 Installation

1. Install **LSPosed** (Zygisk or Riru variant)
2. Download the latest `AkroGhost.apk` from [Releases](../../releases)
3. Install the APK
4. Enable the module in LSPosed → scope it to your Telegram app
5. Force-stop Telegram and reopen

**Supported clients:** Telegram, Telegram Beta, Nagram, NagramX, Nicegram, Forkgram, iMe, TelegramPlus, TGConnect, Telega, XPlus, Momogram, and more.

## 🏗️ Building from Source

```bash
git clone https://github.com/YOUR_USERNAME/AkroGhost
cd AkroGhost
chmod +x gradlew
./gradlew assembleDebug
```

APK will be in `app/build/outputs/apk/debug/`

Or use **GitHub Actions** — just push to `main` branch and the workflow will build automatically.
